# Villa-Saison

Eine Saison lang eine kleine Villa in Ligurien wieder in Gang bringen: 16
Wochen von Ende April bis Ferragosto, Zeit einteilen, renovieren, Gäste
empfangen. Drei Ressourcen – Geld, Zeit, Charme – und eine Villa, die man
beim Renovieren sichtbar verändert.

Grafik und Ton entstehen vollständig aus Code: kein Bild, keine Audiodatei,
kein eingekauftes Asset.

## Befehle

| Befehl | Was es tut |
|---|---|
| `npm run dev` | Entwicklungsserver |
| `npm run balance` | Tausend Saisons je Strategie simulieren, Verteilung der Ausgänge |
| `npm run rauchtest` | Build im Browser durchspielen, Bilder nach `rauchtest/` |
| `npm run build` | Eine einzelne `dist/index.html` |
| `npm run artifact` | `artifact.html` zum Veröffentlichen |
